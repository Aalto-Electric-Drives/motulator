motulator.drive.gradnet#

Gradient-based neural network maps.

The trained networks (see load_gradnet) and the maps based on them (e.g., CurrentMap) are evaluated with NumPy. Training the networks (see training) requires PyTorch.

The map is symmetrized about the d-axis to ensure physical consistency. The map can be sampled on a grid by as_magnetic_model(), e.g., for plotting.

class motulator.drive.gradnet.GradNetFunction[source]#

Trained GradNet as a numpy function in double precision.

The function maps the per-unit input, shape (…, in_dim), to the per-unit output of the same shape, see GradNet. It is created from a trained model by from_model, saved to an npz file by save, and loaded by load_gradnet.

Parameters:

  • W (ndarray, shape (num_modules, embed_dim, in_dim)) – Weights of the modules.

  • b (ndarray, shape (num_modules, embed_dim)) – Biases of the modules.

  • beta_log (ndarray, shape (num_modules,)) – Logarithms of the scales of the activations of the modules.

  • mu_log (ndarray, shape (mu_dim,)) – Logarithms of the coefficients of the linear term.

  • bias (ndarray, shape (in_dim,)) – Bias of the output.

  • activation (str) – Name of the activation function, see ACTIVATIONS.

  • p (int) – Exponent of the p-norm gradient activation (0 for the other activations).

  • psi_base (float) – Base value of the flux linkage (Vs).

  • i_base (float) – Base value of the current (A).

class motulator.drive.gradnet.PlotOptions[source]#

Options for plotting functions.

Parameters:

  • base (BaseValues | None, optional) – Base values for per-unit conversion. If None, SI values are used.

  • lims (dict[str, tuple[float, float]] | None, optional) – Axis limits as {‘x’: (xmin, xmax), ‘y’: (ymin, ymax)}.

  • ticks (dict[str, list[float]] | None, optional) – Axis ticks as {‘x’: [x1, x2, …], ‘y’: [y1, y2, …]}.

  • surface_cmap (str, optional) – Colormap for the surface plot, defaults to “viridis”.

  • latex (bool, optional) – Use LaTeX fonts if True, defaults to False.

  • save_path (str | Path | None, optional) – Path to save the figure. If None, the figure is not saved.

  • savefig_kwargs (Dict[str, Any], optional) – Additional keyword arguments passed to plt.savefig().

  • loci_levels_source ({"ticks", "val", "trn"}, optional) – Source for constant-loci levels in plot_surface_vs_current_and_angle() when plotting over current and angle. If “ticks”, uses ticks[“x”]/ticks[“y”] (with lims/fallback defaults). If “val” or “trn”, uses unique x/y values present in the corresponding point cloud slice.
